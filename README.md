# Mubarak Lawal — Personal Portfolio

> 200-Level Software Engineering Student at Babcock University, Nigeria. Thinking in numbers, building in code.

A personal portfolio built with a focus on restrained minimalism, high contrast, and tactile micro-interactions.

---

## 🛠️ Stack & Technologies

- **Core**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom selector-based dark mode (`@custom-variant dark`)
- **Motion & Interactions**: [GSAP](https://gsap.com/) for mask reveals, 3D perspective depth tilting, and SVG stroke path morphing
- **Icons**: [Lucide React](https://lucide.dev/)

---

## ✨ Features

- **Minimalist Monochrome Aesthetics**: Deep soft zinc dark mode and crisp paper white light mode.
- **Continuous Looping Autograph**: Auto-playing cursive SVG stroke animation tracing "mubarak" with automatic replay cycle.
- **3D Split Cards**: Perspective tilt tracking with layered floating depth slices on hover and tap.
- **Instant Email Copy**: Interactive clipboard copy with checkmark confirmation and automatic timeout reset.
- **Theme Switcher**: Persistent light / dark theme toggle synchronized across document attributes and CSS variables.
- **Mobile First**: Zero horizontal overflow, touch-optimized ergonomics, and fluid typography.

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/posi946/portfolio.git

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
